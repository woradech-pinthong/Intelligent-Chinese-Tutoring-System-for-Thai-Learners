# แต่ละทักษะเราทำยังไง — สอน · ฝึก · วัด (ฉบับพูดได้)

> สรุปจาก [[ออกแบบทักษะ-ฟัง-อ่าน-เขียน]] + [[ทักษะพูด-วิเคราะห์ทางเลือก]] + [[ออกแบบ-แผนเรียนวินิจฉัยนำทาง]] ให้เหลือ "เราทำอะไร" ต่อทักษะ ใช้เล่าให้อาจารย์ฟังตามรูป [[ผังหมวด1-ตามรูปอาจารย์]] · รายละเอียด/เหตุผลอยู่ในไฟล์ต้นทาง · สถานะว่าโค้ดถึงไหนดู [[ตรวจสถานะ-ทักษะ-2026-10-11]]

## 0) โครงเดียวกันทุกทักษะ

- **บันได 3 ขั้น (ที่อาจารย์วาง): เสียง/วรรณยุกต์ → คำ → ประโยค** · ขั้น 0 ทำครั้งเดียวก่อนหมวดแรก · ขั้น 1–2 วนในทุกหมวด
- **ทุกหมวดวนลูป เรียน → ฝึก → วัด → ทวน** · ทวน = FSRS นัดคำที่ใกล้ลืมข้ามหมวดให้เอง
- **2 โหมดกติกาต่างกัน:** โหมดฝึก "ใจดี" (ฟังซ้ำได้ ปรับช้าได้ เฉลยทันที + คำอธิบายแบบคนไทย) · โหมดสอบ "สนามจริง" (เสียงเล่น 2 รอบ ไม่โชว์ข้อความ ไม่เฉลยระหว่างทำ)
- **ทุกคำตอบติดป้ายทักษะ 2 ชั้น:** ชั้น 1 = ด้าน (ฟัง/อ่าน/เรียงประโยค/พูด) · ชั้น 2 = หน่วยความรู้ 23 ตัว (จุดผิดคนไทย 15 + คำศัพท์หมวด 5 + ฟัง/อ่าน/เรียง 3) → โมเดล BKT บอกว่าคนนี้แม่นอะไร อ่อนอะไร → ระบบ**เจาะฝึกจุดอ่อน**ให้ (วินิจฉัยนำทาง)
- **ตัวลวงไม่สุ่ม:** ออกแบบให้ดักจุดที่คนไทยพลาด (วรรณยุกต์ 2/3 · zh/ch/sh · ลำดับคำแบบไทย) — ตอบผิด = รู้ว่าพลาดเรื่องอะไร ไม่ใช่แค่ "ผิด"

## 1) 🎧 ฟัง — HSK 1 สอบ 20 ข้อ (โจทย์มาทางเสียงล้วน)

| | เราทำยังไง |
|---|---|
| **เป้า** | หูแยกเสียงที่คนไทยพลาดได้ → ฟังคำรู้ความหมาย → ฟังประโยค/บทสนทนาจับใจความ |
| **สอน** | ขั้น 0: หน้าวรรณยุกต์ 4 เสียง + คู่เสียง zh/ch/sh (พินอินสี · กดฟังเทียบ) · ขั้น 1: บัตรคำ **เล่นเสียงก่อนเห็นตัวอักษร** ("หูมาก่อนตา") ปรับช้า 0.75x เลือกเสียง ช/ญ · ขั้น 2: ประโยคตัวอย่างในหมวด มีเสียง 2 สปีด |
| **ฝึก** | เกมแยกเสียง: ฟัง 1 เสียง → เลือกพินอิน (ตัวลวง = คู่ 2/3, zh↔z จากคลังจุดผิด) · ฟังคำ → เลือกความหมาย/รูป · ฟังประโยค → จริง/เท็จกับรูป · ฟังบทสนทนา 1 คู่ → ตอบ MCQ · ฟังซ้ำไม่จำกัด เฉลยทันที + คำอธิบายแบบคนไทย |
| **วัด** | ควิซท้ายหมวด ข้อฟัง 4 (เสียงล้วน เล่น 2 รอบ) · pre/post ฟัง 20 ข้อ → คะแนนฟัง 100 · ทุกข้อติดป้าย SKILL-LISTEN + จุดผิดที่ตัวลวงดัก → BKT บอก "แม่นวรรณยุกต์ 2/3 กี่ %" |
| **มิ้นท์** | ได้ยิน 谢谢 → เลือก "ขอบคุณ" จาก [ขอบคุณ · สวัสดี · ลาก่อน · ขอโทษ] · ถ้าพลาดคู่เสียง 2/3 ซ้ำ ระบบส่งไปเกมแยกเสียงคู่นั้น |
| **HSK 2** | ฟังก์ชันเดิม วัตถุดิบยาวขึ้น/เร็วขึ้น/รูปน้อยลง — ไม่ต้องเขียนโค้ดใหม่ |

## 2) 📖 อ่าน — HSK 1 สอบ 20 ข้อ (มีพินอินกำกับ)

| | เราทำยังไง |
|---|---|
| **เป้า** | เห็นตัวจีน (พินอินช่วย) → รู้ความหมาย → อ่านประโยคจับใจความ → ค่อย ๆ "หย่าพินอิน" |
| **สอน** | บัตรคำ: ตัวจีนใหญ่ + พินอินสีตามวรรณยุกต์ + รูป + คำแปล · ประโยคตัวอย่าง 5–10/หมวด มี**ปุ่มซ่อน/โชว์พินอิน** · จุดไวยากรณ์แทรกตามหมวดที่ใช้จริง (的 吗 个 了) |
| **ฝึก** | เห็นคำ → เลือกคำแปล · จับคู่คำ↔รูป / คำ↔แปล · จริง/เท็จ (คำกับรูปตรงไหม) · เติมคำจาก word bank · จับคู่คำถาม↔คำตอบ · ตัวลวง = คู่สับสนทางตา (พินอินต่างแค่วรรณยุกต์ / zh กับ z) |
| **วัด** | ควิซท้ายหมวด ข้ออ่าน 4 (**ไม่มีเสียง** — กฎกระจกของข้อฟัง) · pre/post อ่าน 20 ข้อ → คะแนนอ่าน 100 · ป้าย SKILL-READ + คำศัพท์หมวด |
| **มิ้นท์** | เห็น 你好 nǐ hǎo → เลือก "สวัสดี" · ระดับประโยค: 我是学生 → จับคู่กับคำถาม 你是谁? |
| **HSK 2** | เพิ่ม "ข้อความสั้น 2–3 ประโยค → ตอบคำถาม" เป็นฟังก์ชันใหม่ |

## 3) 🎤 พูด — HSK 1–2 ไม่สอบ (HSKK เป็นการสอบแยก)

| | เราทำยังไง |
|---|---|
| **จุดยืน** | เน้น "สื่อสารได้ ฟังเข้าใจ" ไม่ใช่สำเนียงเจ้าของภาษา · เป็น**โหมดฝึก ไม่ใช่คะแนน** · การประเมินการออกเสียงละเอียด = งานต่อยอด |
| **สอน** | ฟังเสียงต้นแบบ (ช้า/ปกติ) แล้ว**พูดตาม** (shadowing) รูปแบบ HSKK ระดับต้น "ฟังแล้วพูดซ้ำ" · เริ่มจากคำเดี่ยว ~30 คำที่มีเสียง 2/3 และ zh/ch/sh |
| **ฝึก** | กดไมค์ → เบราว์เซอร์ถอดเสียงเป็นข้อความจีน (ไม่บันทึกไฟล์เสียง) → แปลงเป็นพินอิน → เทียบด้วยกฎ: ตรง ✅ · "วรรณยุกต์เพี้ยน: เป้าเสียง 3 ได้ยินเสียง 2" ⚠️ · "ไม่ม้วนลิ้น" ⚠️ · "ยังฟังไม่ชัด ลองใหม่" (ไม่ตัดสินว่าผิด) + คำอธิบายแบบคนไทย |
| **วัด** | ไม่ให้คะแนน ไม่เข้า pre/post ไม่ป้อน BKT รอบแรก — จดเป็นสถิติแยก (asr_hint) ไว้ดูว่า ASR ได้ยินตรงคำกี่ % |
| **มิ้นท์** | พูด 马 mǎ แต่ระบบได้ยิน 麻 má → บอก "วรรณยุกต์เพี้ยน เสียง 3 → 2" พร้อมคำแนะนำว่าเสียง 3 ของจีนต้องกดต่ำแล้วค่อยขึ้น |
| **สถานะ** | ทาง A (นี้) รอทีมเคาะ go/no-go + ตอบอาจารย์ |

## 4) ✍️ เขียน = "ประกอบภาษา" — HSK 1 ไม่สอบ (HSK 2 มี 书写 10 ข้อ)

| | เราทำยังไง |
|---|---|
| **นิยาม** | เลือกคำ/เรียงคำเป็นประโยคที่ถูกไวยากรณ์ — ไม่ใช่คัดลายมือ (อาจารย์รับแล้ว) · HSK 1 = แบบฝึกเสริมดักไวยากรณ์ถ่ายโอนจากไทย ปูฐานสู่ HSK 2 |
| **สอน** | ประโยคตัวอย่างต่อหมวด + จุดที่คนไทยถ่ายโอนผิด: ลำดับคำขยาย (我的书 ≠ หนังสือของฉัน) · ลักษณนาม 个 · ตำแหน่งคำวิเศษณ์ · 了 / 得 |
| **ฝึก** | เรียงคำเป็นประโยค (ลาก/แตะ · ตัวลวง = ลำดับแบบไทย) · เติมคำที่หายไป · เฉลยทันที + อธิบายว่าต่างจากไทยตรงไหน |
| **วัด** | ควิซท้ายหมวด 2 ข้อ (นับในคะแนนเก็บ ไม่เข้า pre/post) · ป้าย SKILL-ORDER + จุดผิดไวยากรณ์ (TL-GRAM-*) |
| **มิ้นท์** | เรียง [书 · 我 · 的] → 我的书 · ถ้าเรียง 书我的 ระบบบอก "จีนเอาคำขยายไว้หน้าคำหลัก ต่างจากไทย" |
| **HSK 2** | เพิ่ม พินอิน → เลือก/พิมพ์อักษรที่ถูก (จำลอง 书写 บนเว็บ) · ฝึกลำดับขีด 100 ตัว = ตัวเลือกเสริม |

## 5) 🧠 ชั้นทักษะที่ 2 — ใช้ร่วมทุกด้าน

- **หน่วยความรู้ 23 ตัว** (ตาราง skills): จุดผิดคนไทย 15 (วรรณยุกต์ 5 · เสียงม้วนลิ้น 5 · ไวยากรณ์ถ่ายโอน 5) + คำศัพท์หมวด 5 + ฟัง/อ่าน/เรียง 3
- **ข้อสอบทุกข้อติดป้าย** ว่าวัดหน่วยไหน (item_skills) → พอตอบ ป้ายติดไปกับคำตอบ (attempts.skill_id)
- **BKT** นับถูก/ผิดรายป้าย → "มิ้นท์แม่นวรรณยุกต์ 2/3 = 40 %" → หน้าหมวด "ทักษะในหมวดนี้" + ระบบเลือกข้อฝึกที่ดักจุดอ่อนนั้นให้ก่อน
- **ทบทวน FSRS** นัดคำที่ใกล้ลืมข้ามหมวด — เป็นความจำคำศัพท์ คนละอย่างกับความแม่นทักษะ
- **สิ่งที่พิสูจน์ในเล่ม:** โมเดลทำนายคำตอบได้ดีกว่าสุ่ม (AUC) และ "มีป้ายจุดผิดคนไทย" ช่วยทำนายดีขึ้นไหม (ablation) · ผู้เรียนได้คะแนน post สูงกว่า pre ไหม (แนวโน้ม ไม่ใช่ข้อสรุปว่าสอบผ่าน)

## 6) พูดให้อาจารย์ฟังใน 30 วินาที

> "ทุกทักษะใช้บันไดเดียวกันครับ เสียง → คำ → ประโยค และวนลูป เรียน-ฝึก-วัด-ทวน ในทุกหมวด · **ฟัง**: ฝึกหูแยกเสียงที่คนไทยพลาดก่อน แล้วฟังคำ ฟังประโยค โจทย์มาทางเสียงล้วนเหมือนข้อสอบ · **อ่าน**: จากคำมีพินอินช่วย ไปประโยค แล้วค่อยซ่อนพินอิน · **เขียน**ของเราคือประกอบภาษา — เรียงคำ/เติมคำ ดักลำดับคำแบบไทย เพราะ HSK 1 ไม่สอบเขียน · **พูด**: ฟังแล้วพูดตาม ใช้ตัวรู้จำเสียงของเบราว์เซอร์ช่วยบอกว่าวรรณยุกต์เพี้ยนหรือไม่ม้วนลิ้น เป็นโหมดฝึก ไม่ให้คะแนน · ที่ต่างจากแอปท่องศัพท์คือ **ทุกข้อติดป้ายว่าวัดจุดผิดคนไทยข้อไหน** และโมเดล BKT ใช้ป้ายนั้นบอกว่าคนนี้อ่อนอะไร แล้วเจาะฝึกให้"
