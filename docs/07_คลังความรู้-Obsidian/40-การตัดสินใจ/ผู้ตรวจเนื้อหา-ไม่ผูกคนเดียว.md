# ผู้ตรวจเนื้อหา — ไม่ผูกคนเดียว ตรวจตามความเสี่ยง (ทีมเคาะ 18 พ.ย. 2026 — หฤทัยเห็นด้วยเอง)

## เดิม
- กติกาทีม / PRD / CG-01: **ทุกชิ้นที่ AI สร้างต้องผ่านหฤทัย (ตะวัน) ก่อนถึงผู้เรียน** — คำแปล · ข้อสอบทุกข้อ · ประโยค · เสียง · Thai-L1 catalog
- RO-03: ปุ่มอนุมัติกดได้เฉพาะบัญชีตะวัน (บอลเป็นแอดมินก็กดแทนไม่ได้) · DB บังคับผ่าน `users.role='approver'` + trigger `items_approver_guard` + ตาราง `approval_transfers` ไว้โอนสิทธิ์ชั่วคราว

## ทำไมเปลี่ยน
- คิวตรวจค้างเป็นเดือน: ประโยคเรียงคำ 10 ประโยค (CG-03) · พินอิน 11 คำ · Thai-L1 catalog 15 KC (C10) ค้างตั้งแต่ ส.ค. — งานโค้ด (ย้ายประโยคลง DB · item bank · 0007) ต้องรอเนื้อหา
- ข้อส่วนใหญ่ของแอป**ปั้นจากคำที่ตรวจครบแล้ว 300/300** — เฉลยและตัวลวงมาจาก DB ตรง ๆ ให้คนตรวจซ้ำทุกข้อไม่ได้เพิ่มความถูกต้อง
- บอล 18 พ.ย.: "กฎที่ตะวันต้องเป็นผู้ตรวจตลอดเสียเวลามาก" · ตะวันเองก็บอกว่า "ไม่จำเป็นต้องให้เขาตรวจหรอก" → **มติร่วมของทีม** ไม่ใช่ฝ่ายเดียว

## กฎใหม่ (รายละเอียดเต็ม = CG-01 / RO-03 ใน `docs/08_สเปค-พัฒนา/กฎการทำงานระบบ-BUSINESS-RULES.md`)
| ระดับ | เนื้อหา | ใครตรวจ |
|---|---|---|
| ก | ข้อฝึก/ควิซที่ตัวสร้างฝั่ง server ปั้นจากคำ/ประโยคที่อนุมัติแล้ว | **กฎตรวจ** (เฉลยจาก DB · ตัวลวงจากคำที่อนุมัติแล้ว · pypinyin · jieba) → approved อัตโนมัติ `generator='auto'` · ใครเจอผิดกด "ระงับ" |
| ข | เนื้อหาแต่งใหม่: คำแปล · ประโยค/บทสนทนา · ข้อจาก `/hsk-item` · คำอธิบาย Thai-L1 · เสียง TTS | **คนในทีมคนใดคนหนึ่ง** ตามเช็กลิสต์ · บันทึก `reviewed_by` / `approved_by` |
| ค | ชุดข้อสอบวิจัย pre/post (เครื่องมือวัดผลในเล่ม) | **หฤทัย (HSK 5) ตรวจครบทุกข้อ ครั้งเดียวก่อนล็อก** |

- หฤทัย = ผู้ตัดสินสุดท้ายเมื่อทีมเห็นไม่ตรงกันเรื่องภาษาจีน + สุ่มตรวจข้อระดับ ก (~10% ก่อนทดลอง) — ไม่ใช่ด่านบังคับทุกชิ้น
- ปุ่มอนุมัติกดได้ทั้ง 2 บัญชี (role approver ให้ทั้งคู่) · `approved_by` บอกว่าใครกด

## ผลต่อระบบ
- DB: trigger `items_approver_guard` เช็ก role approver อยู่แล้ว → ตั้ง role บอล = approver ได้เลย (ข้อมูล ไม่ใช่โครง) · 0007 ต้องเพิ่ม `items.generator` (human | ai_draft | auto) + ยอม approved_by ว่างเฉพาะ generator='auto' · `approval_transfers` หมดความจำเป็นหลัก (พิจารณาตัด)
