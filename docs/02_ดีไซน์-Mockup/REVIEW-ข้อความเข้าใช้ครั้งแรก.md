# ข้อความร่าง หน้าเข้าใช้ครั้งแรก (รอทีมตรวจ)

ข้อความทั้งหมดในไฟล์นี้**เขียนใหม่สำหรับต้นแบบ** ยังไม่อยู่ในแอปจริง · ดูหน้าจอได้ที่ลิงก์ต้นแบบ หน้า "เข้าใช้ครั้งแรก": https://claude.ai/artifact/JDmbfmNBdbZ4iRYpA7K6gE (ต้องแชร์ลิงก์ก่อนถึงเปิดได้)

วิธีตรวจ: แก้ในช่อง "แก้เป็น" ได้เลย ช่องว่าง = ใช้ตามร่าง · ข้อความในแอปเดิมที่ยกมาใช้ซ้ำไม่ได้ลงไว้ในนี้

## ① ต้อนรับ
| ข้อความร่าง | แก้เป็น |
|---|---|
| สวัสดี! เราคือ 小星 ดาวนำทางของคุณ | |
| ดาวนำทาง = คอยบอกว่าวันนี้ควรเรียนอะไรต่อ เราจะไปด้วยกันทีละขั้นนะ | |
| ยินดีต้อนรับสู่ 星航 | |
| ก่อนเริ่ม มี 3 ขั้น · รวมราว 5 นาที | |
| อ่านว่าแอปเก็บอะไร และเก็บไปทำไม | |
| เป้าหมาย วันสอบ และภาษาจีนของคุณตอนนี้ — ข้ามได้ทุกข้อ | |
| 8 ข้อ ราว 3 นาที — ตอบไม่ได้ไม่เป็นไรเลย | |
| บอกกันตรง ๆ ก่อนเริ่ม: แอปนี้เน้นคำศัพท์ การฟัง และการอ่าน ยังไม่ได้ตรวจการพูดและสำเนียงของคุณ — ถ้าได้เรียนกับครูควบคู่ไปด้วยจะดีที่สุด | |
| ครบ 3 ขั้นแล้ว เริ่มเรียนคำแรกได้เลย | |
| (เวลาแต่ละขั้น) อ่านราว 1 นาที · ไม่ถึง 1 นาที ข้ามได้ทุกข้อ · ราว 3 นาที | |

## ② ยินยอมเก็บข้อมูล
| ข้อความร่าง | แก้เป็น |
|---|---|
| ขอความยินยอมเก็บข้อมูล | |
| แอปต้องเก็บประวัติการตอบของคุณ ถึงจะจัดตารางทวนและวัดความแม่นให้ได้ — อ่านสั้น ๆ 3 ข้อนี้ก่อนนะ | |
| เก็บอะไร: ประวัติการตอบของคุณ — ข้อไหน ตอบอะไร ถูกหรือผิด ใช้เวลาเท่าไร และคำตอบ 3 คำถามในขั้นถัดไป | |
| เก็บไปทำไม: จัดตารางทวนคำให้พอดีกับที่คุณจำได้ และวัดว่าแต่ละทักษะแม่นขึ้นแค่ไหน | |
| ถอนความยินยอมได้: ถอนได้ภายหลัง ระบบจะล้างข้อมูลที่บอกว่าเป็นคุณ (เช่น ชื่อ) ส่วนประวัติการตอบจะเหลือแบบไม่ระบุตัวตน | |
| [ข้อความยินยอมฉบับจริง — รอปรึกษาอาจารย์] | **รออาจารย์ (ON-05)** |
| (ถ้ากดไม่ยอมรับ) ไม่เป็นไร ขอเล่าเหตุผลก่อนนะ | |
| ถ้าไม่มีประวัติการตอบ แอปจะไม่รู้ว่าคุณจำคำไหนได้แล้ว และคำไหนควรทวน | |
| แอปจึงยังไม่มีโหมดใช้งานแบบไม่เก็บข้อมูล — ถ้าไม่ยินยอม ตอนนี้จะยังเริ่มเรียนไม่ได้ | |
| ยินยอมแล้วเปลี่ยนใจทีหลัง ก็ถอนความยินยอมได้ · เปลี่ยนใจเมื่อไร ก็กลับมากดยอมรับได้เสมอ | |

## ③ 3 คำถามเริ่มต้น
| ข้อความร่าง | แก้เป็น |
|---|---|
| เลือกเป้า แล้วแอปจะคำนวณแผนให้ — ทุกคนเริ่มที่วันละ 10 คำ | |
| แทีมสอบในปฏิทิน แอปจะนับวันให้เอง | |
| เลือกข้อที่ใกล้ตัวคุณที่สุด ตอบตามจริงได้เลย ไม่มีถูกผิด | |
| เลือกคำตอบ แล้วตรงนี้จะบอกว่ามีผลกับแผนเรียนยังไง | |
| (เป้า HSK 1) เป้า 300 คำ · เรียนวันละ 10 คำ ครบในราว 30 วัน | |
| (เป้า HSK 2) เป้า 500 คำ ครบในราว 50 วัน · บอกไว้ก่อน: ตอนนี้แอปมีเนื้อหาช่วง HSK 1 (300 คำแรก) — เส้นทางเหมือนกัน แค่นับเป้าเป็น 500 คำ | |
| (ยังไม่คิดเรื่องสอบ) เรียนตามจังหวะของคุณ · เริ่มที่วันละ 10 คำ ไม่ต้องรีบ | |
| (มีวันสอบ เวลาพอ) เหลือ N วัน · เรียนวันละ 10 คำ ครบในราว Y วัน — ทันสบาย | |
| (เวลาไม่พอ) …ซึ่งนานกว่าเวลาที่มี — ถ้าอยากครบก่อนสอบ ต้องเรียนราว R คำ/วัน · เกิน 20 คำต่อวันถือว่าหนัก — เลือกวันนี้ต่อได้นะ หรือลองวันที่ไกลกว่านี้ก็ได้ | |
| (ไม่มีวันสอบ) ไม่มีวันสอบก็ไม่เป็นไร · จะไม่มีนับถอยหลัง — ใช้เป้าวันละ 10 คำ และดูความคืบหน้าเป็นรายสัปดาห์แทน | |
| (อ่านไม่ออกเลย) ไม่เป็นไรเลย · แอปนี้ออกแบบให้เริ่มจากศูนย์ได้ — หลังแบบทดสอบ เราจะพาไปเริ่มที่ปูพื้นฐานเสียง (พินอินและวรรณยุกต์) ก่อน | |
| (ตอบข้ออื่น) จดไว้แล้ว · แบบทดสอบในขั้นถัดไปจะช่วยบอกว่าควรเริ่มที่ปูพื้นฐานเสียง หรือหมวด 1 | |
| แก้คำตอบนี้ทีหลังได้ที่แท็บ "ฉัน" | **ยังไม่มีในแอป** |
| ตัวเลือกข้อ 3 (ปรับขีดเป็น "หรือ"): ทักทาย นับเลขได้บ้าง หรือเคยเรียนพินอิน | |

## ④ ก่อนทำแบบทดสอบ
| ข้อความร่าง | แก้เป็น |
|---|---|
| ยังไม่เฉลยรายข้อ เพราะชุดนี้จะกลับมาให้ทำอีกครั้งหลังเรียน ไว้วัดว่าคุณพัฒนาขึ้นแค่ไหน | |
| ไม่รู้ก็เดาได้เลย คะแนนนี้ไว้เทียบพัฒนาการ ไม่ใช่สอบผ่านหรือตก | |
| ข้อฟังจะเล่นเสียงเอง เปิดเสียงไว้ด้วยนะ แตะปุ่มลำโพงเพื่อฟังซ้ำได้ | |
| ทำเสร็จแล้ว จะเห็นผลรายทักษะ แล้ว 小星 จะบอกว่าควรเริ่มเรียนตรงไหน | |
| ทุกคนทำขั้นนี้ครั้งเดียว ก่อนเริ่มเรียน | |

## ⑤ หน้าแรกครั้งแรก
| ข้อความร่าง | แก้เป็น |
|---|---|
| หน้านี้บอกว่าวันนี้ควรทำอะไร — ทำตามการ์ดด้านล่างทีละขั้นก็พอ | |
| ดาวนำทาง = สิ่งที่ควรทำต่อ | |
| เข้าไปแล้วทำแค่นี้ · แตะบัตรคำเพื่อพลิกดูคำแปล · แตะปุ่ม "ฟัง" เพื่อฟังเสียงอ่าน | |
| วันแรกของคุณ · ทำแล้ว 1 จาก 3 | |
| ใช้เทียบว่าคุณเก่งขึ้นแค่ไหนในภายหลัง | |
| พลิกดูคำไหนแล้ว นับเป็น 1 คำ | |
| คำที่เรียนวันนี้จะเข้าคิวทวนให้อัตโนมัติ ไม่ต้องจำเองว่าต้องทวนคำไหน | |
| เส้นทางของคุณ · แต่ละเกาะคือ 1 หมวด — เรียนไปแล้วเกาะจะค่อย ๆ ชัดขึ้น | |
| (กรณีเริ่มปูพื้นฐานเสียง) จากแบบทดสอบ ส่วนการฟังยังใหม่สำหรับคุณ · ลองฟัง 4 เสียงวรรณยุกต์ · ฝึกหูแยกคู่เสียงที่คนไทยแยกยาก | |
| (ลิงก์ข้าม) ไปหมวด 1 ก่อนได้ แล้วฝึกหูแทรกวันละนิด — ช่วงแรกอาจฟังไม่ค่อยทัน | |
| ทัวร์ 1: เริ่มที่นี่ทุกวัน · แตะปุ่มนี้ แอปจะพาไปสิ่งที่ควรทำต่อ | |
| ทัวร์ 2: เมนูล่าง 4 ช่อง · อยู่ล่างสุดทุกหน้า แตะเพื่อไปหน้าอื่นได้ทุกเมื่อ (วันนี้ = สิ่งที่ต้องทำวันนี้ · เส้นทาง = แผนที่ทั้งหมด 5 หมวด · บัตรคำ = คำศัพท์ทั้งหมด · ฉัน = ผลการเรียนและตั้งค่า) | |
| ทัวร์ 3: ดูว่าไปถึงไหนแล้ว · แตะป้าย HSK 1 นี้ (อยู่บนสุดทุกหน้า) เพื่อดูเส้นทางและความคืบหน้าของคุณ | |
| ปุ่ม "วิธีใช้" (เปิดทัวร์ซ้ำ) — เพิ่มเองนอกสเปค เอาหรือไม่เอา | |

## เรื่องที่ต้องตัดสิน (นอกเหนือจากถ้อยคำ)
- ข้อความยินยอมฉบับจริง (ON-05) รออาจารย์ — ฉบับจริงต้องบอกการใช้ข้อมูลเพื่องานวิจัย และช่องทางถอนความยินยอม
- ผังผู้ใช้วางขั้นสมัคร/เข้าสู่ระบบไว้ระหว่างยินยอมกับ 3 คำถาม แต่ต้นแบบยังไม่มีหน้านี้
- ตัวเลือกข้อ 3 "เคยเรียนมาแล้ว" ยังรอเคาะว่าคงไว้ไหม (ฐานข้อมูลรองรับอยู่แล้ว)
- จำนวนข้อแบบทดสอบ "8 ข้อ" มาจากชุดเดโม ชุดจริงยังไม่สรุป (40 หรือฉบับย่อ) ตัวเลขบนจอจะเปลี่ยน
- เกณฑ์คะแนนฟังที่ใช้แนะนำปูพื้นฐานเสียง (PL-05) ยังไม่มีตัวเลข
- ระดับ "ปูพื้นฐานเสียง" ในโค้ดยังตั้งว่าเปิดไม่ได้ แต่หน้าแรกแนะนำให้เริ่มที่นี่
- ปฏิทินใช้ปี พ.ศ. (2569) — ยืนยันว่าใช้ พ.ศ.
- เวลาแต่ละขั้น (1 นาที / 3 นาที / รวม 5 นาที) เป็นตัวเลขประมาณ ยังไม่ได้จับเวลาจริง
